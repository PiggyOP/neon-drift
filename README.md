# NEON DRIFT

A tiny neon canvas arcade game: drift through a glowing arena, dodge a growing swarm, and collect energy to score points and clear nearby enemies.

## Play

Open `index.html` in a browser. No installation, libraries, or external assets required.

- **WASD / arrow keys:** move
- **Space:** start or restart
- **Mint energy:** earn 10 points and clear enemies within the pulse radius
- **Pink enemies:** avoid them to survive

Best score is kept for the current browser session.
